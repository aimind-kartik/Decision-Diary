# WMD Experiment Mapping

| Experiment | Status in Decision Diary |
|---|---|
| 1: HTML5 & CSS3 | Implemented with semantic layout, forms, tables, responsive CSS and accessible labels. |
| 2: REST API & CRUD | CRUD is implemented against LocalStorage (not a real REST API): users create, read, update and delete local decisions. |
| 3: React & JSX | Implemented through reusable pages/components and dynamic comparison data. |
| 4: Hooks & Context API | Implemented with `useState`, `useEffect`, Context API and form validation. |
| 9: Deployment | Vite project is deployment-ready; deployment is intentionally not performed. |

## Documented future extensions

Experiments 5–8, 10 and 11 are not implemented. Their objectives could be related in a future version as follows: a Java/Spring service (5) could replace LocalStorage; Android/native mobile concepts (6) could expose the same comparisons on mobile; database concepts (7) could provide authenticated cloud persistence; security/authentication (8) could protect accounts; cloud hosting/DevOps (10) could automate production deployment; and advanced integrations/analytics (11) could provide verified lifecycle sustainability datasets. Each would require its own backend, data model, privacy design and deployment configuration.
